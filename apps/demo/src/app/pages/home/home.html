Architecture

Three Layers. One Token Engine.

The CDK provides behavior primitives. Core adds the Angular component shell. Theme delivers the design-token engine that powers everything seamlessly.

CDK

Behavior Primitives

Pure TypeScript. CVA base, form models, focus management, keyboard navigation, and animation helpers — zero Angular framework runtime lock-in.

@ngxsmk/cdk
Core

Angular Components

150+ standalone components. Signal inputs, two-way models, template outlets via InjectionTokens, and token-driven styling.

@ngxsmk/core/*
Theme

Design-Token Engine

HSL coordinates → CSS custom properties. Supports vanilla CSS, SCSS, Tailwind v3 preset, Tailwind v4 theme, and Ionic adapter. Dark mode via .dark class.
