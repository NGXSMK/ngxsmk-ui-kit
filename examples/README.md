# Examples

Small, runnable apps that show how to consume NGXSMK outside the monorepo.

| Example                                           | What it demonstrates                                      |
| ------------------------------------------------- | --------------------------------------------------------- |
| [`quickstart`](./quickstart)                      | Zoneless Angular + card / form / dialog / dark mode       |

[Open the quickstart in StackBlitz](https://stackblitz.com/github/NGXSMK/ngxsmk-ui-kit/tree/main/examples/quickstart?file=src%2Fapp%2Fapp.ts).

Each example depends on published `@ngxsmk/*` packages from npm (not on the
workspace sources), so it mirrors a real consumer install.
